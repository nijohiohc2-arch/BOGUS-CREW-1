1

가입 · 로그인메인 페이지에서 시작해요

처음이면 ✨ 크루 가입, 이미 가입했다면 🔑 로그인 탭을 눌러요. 이메일이 필요 없고 이름과 비밀번호만 기억하면 어느 기기에서든 로그인할 수 있어요.

  1. 이름(활동명)을 입력해요. 이 이름이 곧 내 계정이라, 로그인할 때도 똑같이 입력해야 해요.
  2. 비밀번호는 6자리 이상으로 정해요.
  3. 크루 가입하기 →를 누르면 가입이 끝나고 바로 내 관리 페이지로 이동해요.
  4. 이미 가입했다면 로그인 탭으로 바꿔 이름·비밀번호를 넣고 로그인 →을 눌러요.
⚠️ 같은 이름으로는 한 번만 가입할 수 있어요. “이미 가입된 이름이에요”라고 나오면 로그인 탭을 이용하세요. 비밀번호가 틀리면 “이름 또는 비밀번호가 틀렸어요”라고 알려줘요.
2

내 관리 페이지 열기로그인하면 바로 이용할 수 있어요

로그인 상태로 메인에 다시 오면 “OOO님, 반갑습니다! 👋”와 함께 두 개의 버튼이 보여요.

  1. 🗂️ 내 관리 페이지 열기 — 내 기록을 입력하는 메인 작업 공간이에요.
  2. 📊 크루 전체 활동 현황 보기 — 로그인 없이도 볼 수 있는 크루 순위 화면이에요.

공용 기기라면 사용 후 로그아웃을 눌러 주세요.

관리 페이지 상단 살펴보기

관리 페이지(Review Growth OS) 맨 위에는 내 설정과 요약이 모여 있어요.

  1. 내 비밀번호 — 👁을 누르면 보이고 다시 누르면 가려져요. 잊어버렸을 때 여기서 확인해요.
  2. 통계 공개 스위치 — 공개중이면 내 기록이 활동현황에 보이고, 비공개로 바꾸면 숨길 수 있어요.
  3. 📊 크루 현황 버튼 — 언제든 활동현황 화면으로 이동해요. 그 옆에 🎨 테마(다크→라이트→파스텔), 📥 CSV(내 기록 다운로드), 로그아웃이 있어요.
  4. 총 요청함 · 총 요청받음 · 전체 차이 — 내가 부탁한 건수와 받은 건수, 그 차이(+ 더 부탁함 / − 더 받음 / ±0 균형)예요.
  5. 날짜별 완료 통계 — 상태를 완료로 바꾼 건이 날짜별 카드로 쌓여요. 옆으로 밀어서 볼 수 있어요.
  6. 기록 표 — 리뷰어 40칸이 미리 만들어져 있어요. 아래에서 자세히 설명할게요.
3

리뷰 · 활동 입력기록 표에 한 줄씩 채워요

표의 한 줄이 리뷰어 한 명이에요. 각 칸은 위 줄 = 요청함(내가 부탁한 쪽), 아래 줄 = 요청받음(내가 부탁받은 쪽)으로 나뉘어 있어요. 모바일에서는 표를 좌우로 밀어서 나머지 칸을 볼 수 있고, 번호·이름은 왼쪽에 고정돼요.

① 수량 · 상태 · 날짜

  1. 수량 − / + — 요청함/요청받음 건수를 누를 때마다 1씩 바꿔요. 오른쪽 ± 배지에 차이가 바로 계산돼요.
  2. 상태 — 대기중 → 진행중 → 완료 중에서 골라요. 완료로 바꾸면 위쪽 날짜별 완료 통계에 반영돼요.
  3. 요청한날 / 받은날 — 날짜 칸을 눌러 달력에서 골라요. 기본값은 오늘이에요.
💾 입력하면 약 1초 뒤 자동 저장돼요. 저장 버튼은 따로 없어요.

② 송금액 · 계좌 · 주소 · 링크 · 메모

  1. 송금액 / 받은금액 — 버튼을 누르면 기록 창이 열려요. 날짜와 금액을 넣고 + 추가를 누르면 내역이 쌓이고 합계가 계산돼요.
  2. 계좌 · 주소 — 텍스트를 적고 옆 📋를 누르면 클립보드에 복사돼요.
💬 카톡오픈채팅 URL을 저장해 두면 버튼 한 번으로 채팅을 열어요. 수정은 길게 누르기(PC는 우클릭).
📎 제품사진사진을 올리면 상태가 완료로 자동 변경돼요. 썸네일을 누르면 크게 봐요.
🔗 상품페이지요청한 링크 / 받은 링크를 각각 적어요.
📝 기타내용요청 메모 / 받은 메모로 자유롭게 기록해요.
⚠️ 아래 줄(요청받음) 칸과 송금·사진 기록 일부는 지금 쓰는 기기의 브라우저에만 저장돼요. 다른 기기·브라우저에서는 안 보일 수 있으니 중요한 내용은 📥 CSV로 백업해 두세요.
4

활동현황 확인크루 전체 순위를 한눈에

메인의 📊 크루 전체 활동 현황 보기 또는 관리 페이지의 📊 크루 현황으로 들어가요. 로그인하지 않아도 볼 수 있어요.

  1. 요약 카드 3개 — 크루 인원 · 총 완료 · 총 요청
  2. 크루 순위 — 완료 건수가 많은 순서로 정렬되고, 1~3위는 🥇🥈🥉 메달이 붙어요.
  3. 진행 바 — 1위 대비 내 완료 비율만큼 초록 막대가 채워져요.
  4. 각 카드에는 요청함 · 요청받음 건수와 오른쪽 큰 숫자로 완료 건수가 표시돼요.
🔄 화면은 1분마다 자동 갱신돼요. 관리 페이지에서 상태를 완료로 바꾸면 잠시 뒤 순위에 반영돼요. 내 기록을 숨기고 싶다면 통계 공개를 비공개로 바꾸세요.

활동현황 미리보기움직이는 예시 화면 · 샘플 데이터

실제 활동현황이 어떻게 채워지고 바뀌는지 샘플 데이터로 보여드려요. 카드가 차례로 나타나고, 숫자가 올라가고, 막대가 채워진 뒤, 새 완료가 등록되면 순위가 바뀌는 과정이 반복돼요.

자주 묻는 질문막힐 때 여기를 확인하세요

비밀번호를 잊어버렸어요
다른 기기에 로그인된 상태라면 관리 페이지의 내 비밀번호 👁에서 확인할 수 있어요. 어디에도 로그인되어 있지 않다면 운영진에게 문의해 주세요.
“이미 가입된 이름이에요”라고 나와요
그 이름으로 이미 계정이 만들어져 있어요. 🔑 로그인 탭에서 같은 이름과 비밀번호로 들어가세요. 이름은 띄어쓰기까지 똑같이 입력해야 해요.
입력했는데 저장이 됐는지 모르겠어요
입력 후 약 1초 뒤 자동 저장돼요. 페이지를 새로고침해도 값이 그대로면 저장된 거예요. 일부 항목(아래 줄 칸, 송금·사진 기록)은 이 기기 브라우저에만 저장되니 CSV 백업을 권해요.
표가 옆으로 길어서 불편해요
표를 손가락으로 좌우로 밀면 나머지 칸이 보여요. 번호·이름·품앗이 칸은 왼쪽에 고정돼 있어요. 글자가 작으면 화면을 가로로 돌려 보세요.
내 기록을 다른 크루원이 볼 수 있나요?
활동현황에는 이름과 요청/완료 건수가 보여요. 원하지 않으면 관리 페이지의 통계 공개 스위치를 비공개로 바꾸세요. 계좌·주소·메모는 활동현황에 나오지 않아요.
화면 색을 바꾸고 싶어요
관리 페이지 상단의 🎨 테마 버튼을 누를 때마다 다크 → 라이트 → 파스텔 순서로 바뀌어요.
